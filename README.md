## 🏠 Tentang Proyek

**Griya Taman Belibis** adalah proyek perumahan subsidi yang dikembangkan oleh **PT. Bydara Jaya Develindo** di Kota Solok, Sumatera Barat. Website ini berfungsi sebagai halaman pemasaran digital untuk menampilkan informasi proyek, katalog unit rumah, simulasi KPR, dan form pemesanan online.

### Visi

Menjadi pengembang properti terpercaya yang menghadirkan hunian berkualitas dengan sentuhan Islami di Sumatera Barat.

### Target Pengguna

| Pengguna | Kebutuhan |
|----------|-----------|
| 🏠 Calon pembeli rumah | Melihat unit, harga, lokasi, dan melakukan booking |
| 💰 Pencari simulasi KPR | Menghitung cicilan bulanan |
| 📊 Investor properti | Melihat progres dan potensi proyek |
| 🌐 Calon klien web dev | Melihat portofolio jasa pembuatan website |

## 🛠️ Setup Lokal

### Prasyarat

- [Node.js](https://nodejs.org/) >= 18.0.0
- [npm](https://www.npmjs.com/) >= 9.0.0 (atau yarn/pnpm)
- [Git](https://git-scm.com/)

### Instalasi

```bash
# 1. Clone repository
git clone https://github.com/bydarajaya/bydara-jaya-develindo.git

# 2. Masuk ke directory project
cd bydara-jaya-develindo

# 3. Install dependencies
npm install

# 4. Jalankan development server
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

### Script Tersedia

| Script | Deskripsi |
|--------|-----------|
| `npm run dev` | Jalankan development server (hot reload) |
| `npm run build` | Build untuk production |
| `npm run start` | Jalankan production server |
| `npm run lint` | Jalankan ESLint checks |

### Clone Alternatif

```bash
# Via SSH
git clone git@github.com:bydarajaya/bydara-jaya-develindo.git

# Via GitHub CLI
gh repo clone bydarajaya/bydara-jaya-develindo
```

## 🔧 Troubleshooting

### Masalah Umum

<details>
<summary><b>❌ npm install gagal</b></summary>

```bash
# Clear cache
npm cache clean --force

# Hapus node_modules
rm -rf node_modules

# Install ulang
npm install
```

</details>

<details>
<summary><b>❌ Port 3000 sudah digunakan</b></summary>

```bash
# Jalankan di port lain
npm run dev -- -p 3001
```

</details>

<details>
<summary><b>❌ Gambar tidak muncul</b></summary>

- Pastikan koneksi internet aktif (gambar dari picsum.photos)
- Cek blocklist browser/adblocker
- Gambar placeholder bersifat eksternal

</details>

<details>
<summary><b>❌ Build error TypeScript</b></summary>

Saat ini `ignoreBuildErrors: true` diaktifkan di `next.config.mjs`. Untuk production, non-aktifkan dan perbaiki error:

```javascript
// next.config.mjs
const nextConfig = {
  typescript: { ignoreBuildErrors: false },
  eslint: { ignoreDuringBuilds: false },
};
```

</details>

<details>
<summary><b>❌ WhatsApp link tidak berfungsi</b></summary>

- Format nomor harus internasional: `62xxxx` (tanpa `+` atau `0` depan)
- Cek `siteConfig.whatsapp` di `src/lib/data.ts`

</details>

## ❓ FAQ

<details>
<summary><strong>Apakah ini situs resmi PT. Bydara Jaya Develindo?</strong></summary>

Tidak. Ini adalah landing page informasional yang dibangun oleh Ran Dev sebagai portofolio/pembantu pemasaran. Hubungi kontak resmi untuk informasi valid.

</details>

<details>
<summary><strong>Bagaimana cara mengubah harga unit?</strong></summary>

Edit file `src/lib/data.ts`, cari array `unitTypes` dan ubah nilai `price` pada objek unit yang diinginkan.

</details>

<details>
<summary><strong>Bagaimana cara menambah unit baru?</strong></summary>

Tambah objek baru ke array `unitTypes` di `src/lib/data.ts` dengan mengikuti interface `UnitType` yang sudah ada.

</details>

<details>
<summary><strong>Apakah ada database?</strong></summary>

Tidak ada. Semua data bersifat statis dan di-hardcode di `src/lib/data.ts`. Form booking langsung redirect ke WhatsApp tanpa menyimpan data di server.

</details>

<details>
<summary><strong>Bagaimana cara deploy ke production?</strong></summary>

Klik tombol "Deploy with Vercel" di atas, atau jalankan `vercel` di terminal. Tidak perlu environment variables.

</details>

<details>
<summary><strong>Apakah support dark mode?</strong></summary>

CSS variables untuk dark mode sudah terkonfigurasi di Tailwind, namun belum diaktifkan secara default. Toggle dark mode dapat ditambahkan nanti.

</details>
